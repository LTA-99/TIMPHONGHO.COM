# Images

Put profile images here, then update `frontend/data/profile.json`.

Example:

```json
{
  "coverImage": "./assets/images/cover.jpg",
  "avatarImage": "./assets/images/avatar.jpg"
}
```

Recommended sizes:

- `cover.jpg`: 960 x 320 or larger
- `avatar.jpg`: square image, at least 300 x 300
